第一章 声音的物理本质：音乐从何而来

1.1 声波：音乐的”原材料”

音乐的本质是声音，而声音的本质是振动。当一个物体（如吉他的弦、钢琴的锤、人的声带）振动时，它周围的空气分子会被交替压缩和稀疏，形成肉眼看不见但耳朵能捕捉的声波。

声波有三个最基本的物理参数：

参数名称 物理定义 在音乐中的表现
振幅（Amplitude） 振动过程中偏离平衡位置的最大距离 音量（响度），振幅越大声音越响
频率（Frequency） 单位时间内的振动次数，单位是赫兹（Hz） 音高，频率越高音高越高
波形（Waveform） 振动随时间变化的形态模式 音色，不同乐器即使音高相同听起来也不同

1.2 频率与音高的关系

音高与频率之间不是简单的线性关系，而是对数关系。这是理解音乐物理学最关键的一点。

以标准音 A4（钢琴上中央C右边的A） 为例，它的频率是 440 Hz，这意味着它每秒振动440次。

从 A4 向上一个八度到 A5，频率翻倍为 880 Hz；向下到 A3，频率减半为 220 Hz。这说明：

规律：每升高一个八度，频率 × 2；每降低一个八度，频率 ÷ 2。

这个规律在音乐中非常重要，因为它解释了为什么不同八度的同一个音听起来”像”同一个音——因为高频恰好是低频的整数倍，谐波高度重合，人的听觉系统会将它们识别为同一音高家族的不同成员。

1.3 人类听觉的秘密

人类能听到的频率范围大约是 20 Hz 到 20,000 Hz。但这个范围随着年龄增长会逐渐缩小，尤其是高频部分。

更神奇的是，人耳对 1000 Hz 到 4000 Hz 这个范围最为敏感——这恰好是人声说话和唱歌的主要频率范围。大自然花了数百万年塑造了我们的耳朵，让它对人声最为敏感，因为人声是原始人类最重要的交流工具。

在音乐中，这个特性意味着：

  • 人声为主旋律的歌曲最容易”入耳”
  • 贝斯和鼓的低频（60 Hz - 250 Hz）不需要太大音量就能产生”存在感”
  • 吉他等乐器的中高频（250 Hz - 4000 Hz）最容易与 vocal 竞争，需要 EQ 调整

1.4 谐波与音色的奥秘

为什么钢琴弹出来的 A4 和小提琴拉出来的 A4 完全不同？

答案在于 谐波（Harmonics / Overtones）。

当一个音发声时，振动源（弦、空气柱等）不只做一个完整的振动，而是同时进行多重振动：

  • 基音（Fundamental）：振动源整体振动一次产生的音，决定我们感知的音高
  • 泛音（Overtones）：振动源分段振动（二等分、三等分、四等分……）同时产生的音，叠加在基音上

以一根 A4 弦为例（基频 440 Hz）：

不同乐器的泛音结构完全不同：

  • 钢琴的泛音衰减较快，音色”干脆”
  • 小提琴的泛音丰富且持续，音色”悠长”
  • 长笛几乎没有偶数泛音，音色”纯净”
  • 电吉他失真会人为增强某些泛音，产生”粗犷”的质感

理解谐波是理解音色的关键，也是混音、编曲、配器的理论基础。

1.5 声音的空间属性

真实世界中的声音还有三个空间维度：

1. 音场（Sound Field）

  • 声源宽度（Stereo Width）：左-右定位
  • 纵深（Depth）：前-后层次感，通过混响（Reverb）和延迟（Delay）实现

2. 动态（Dynamic）

  • 声音从最弱到最强的变化范围
  • 古典音乐的动态范围可达 50 dB 以上
  • 现代流行音乐动态范围被压缩得很小（ Loudness War 的代价）

3. 空间混响（Reverb）

  • 不同空间（房间、大厅、教堂、室外）产生不同的反射声
  • 混响时间（RT60）决定空间的”大小感”
  • 现代音乐几乎所有轨道都加了一定量的混响来”融合”声部

没有音程，音乐将是一堆孤立无关联的音符；有了音程，音符才能被组织成旋律与和声。

2.5 三全音：音乐中最不安分的音程

三全音（Tritone） 跨越 6 个半音（减五度 = 增四度），是距离根音最远的自然音程。

三全音的历史：

  • 文艺复兴后被接受，广泛用于：
    • 歌剧中的”恶魔角色动机”
    • 爵士音乐中的 tritone substitution
    • 电影配乐中的神秘/危险场景
    • 摇滚/金属的失真音色

第三章 十二平均律：现代音乐的基石

3.1 为什么需要十二平均律？

在音乐史的长河中，人类尝试过许多不同的音律系统。古希腊的五度相生律、中国先秦的三分损益法、中世纪的纯律……每种系统都有其独特的美，但也都面临一个致命问题——无法自由转调。

以五度相生律为例：如果从 C 开始，连续向上叠加纯五度（C → G → D → A → E → B → F# → C# → G# → D# → A# → E# → B#），经过12次五度叠加后，最后得到的音比出发点高约 23.5 cents（音分，1 cent = 1/100 半音）。这个微小的差异叫做毕达哥拉斯 comma。

结果是什么呢？如果你用五度相生律调一架钢琴，从 C 大调弹到 F 大调，听起来还挺和谐；但从 C 大调弹到 Gb 大调，可能就”跑调”了。

十二平均律（Equal Temperament） 的天才解决方案是：不再追求每个音程的”绝对纯度”，而是把一个八度均分为12个完全相等的半音，每个半音的频率比固定为：

这个数看起来有点奇怪，但它的数学特性非常优雅：连续乘以12次²√2，恰好等于 2（即回到八度）：

这意味着在十二平均律中，所有12个调完全平等——无论从哪个音开始建立音阶，结构都完全一样。作曲家可以自由地在任意调之间转调，不需要为每个调单独调音。

3.2 十二平均律的数学之美

让我们用 A4 = 440 Hz 精确计算相邻半音的频率：

音分（Cents） 是描述微小声高差异的单位：

  • 1 cent = 1/100 半音
  • 100 cents = 1 个半音
  • 1200 cents = 1 个八度

十二平均律中，每个半音 = 100 cents，完全均匀。这是韦克迈斯特八度（Werckmeister temperament）等早期平均律方案追求的目标，而现代十二平均律完美实现了它。

每组7个白键 + 5个黑键 = 12个音，循环重复。钢琴设计完美对应了十二平均律的12音体系。

3.4 等音：同一个音，不同的名字

在十二平均律中，由于半音是均匀划分的，有些音的频率完全相同，但记谱和叫法不同——这叫做等音（Enharmonic Equivalents）：

虽然频率相同，但等音在和声语境中有不同的含义：

  • C# 大调的调号为 7 个升号，色彩偏”明亮/古典”
  • Db 大调的调号为 5 个降号，色彩偏”柔和/浪漫”
  • 爵士乐中，Db7 常被记为 C#7（习惯用法）

3.5 十二平均律的代价与收益

代价：

  • 十二平均律中，除了纯八度和纯五度（各偏离约 2 cents），其他所有音程都不”纯”
  • 大三度比纯律大三度宽约 14 cents，听起来”稍亮”
  • 纯律中的和声（尤其是大调三和弦）比十二平均律更”温暖”
  • 一些古典音乐学家认为十二平均律”杀死”了音乐的情感深度

收益：

  • 任意调性间自由转调
  • 乐器标准化成为可能（钢琴、吉他等）
  • 作曲家的创作空间极大扩展
  • 现代流行音乐、爵士、电子音乐得以蓬勃发展

历史事实：十二平均律在16-17世纪由荷兰数学家西蒙·斯特芬（Simon Stevin）首先从数学上提出，但受限于乐器制造技术未能实现。直到19世纪，随着钢琴制造技术的成熟，十二平均律才成为全球音乐的标准。

第四章 音阶与调式：音乐的色彩语言

4.1 什么是音阶？

音阶（Scale） 是一组按照特定规则排列的音符。简单理解，音阶就是音乐的”词汇表”——从这张词汇表中选择音符，构建旋律与和声。

音阶有几个关键参数：

  • 起始音（Root）：音阶的”家”，通常是大调或小调的主音
  • 音数（Scale Degrees）：音阶中每个音的名称（1-7，主音到导音）
  • 音程结构（Interval Pattern）：音阶中全音和半音的排列顺序

类比：如果音乐是语言，音阶就是字母表。和弦是词汇，词汇组成语法（和弦进行），语法组织成句子（旋律与和声）。

4.2 自然大调：最”标准”的颜色

自然大调（Natural Major Scale） 是西方流行音乐中最重要的音阶，也是大多数人听到”开心”的音乐时会想到的声音。

结构公式：全音 - 全音 - 半音 - 全音 - 全音 - 全音 - 半音

C 大调完整音阶：

为什么大调听起来”开心”？

关键在于三度音（C 到 E）是大三度（4个半音）。大三度是一个不完全协和音程——它既和谐（因为离纯五度 C-G 不远），又带有明亮的光泽。小调的三度音是小三度，听起来更”暗”，因此产生忧郁感。

唱名（Solfege）系统是学习音阶的好工具：

  • Do = 主音（home）
  • Re = 上行运动的起点
  • Mi = “我在哪里”的参照点
  • Fa = 向属音过渡
  • Sol = 稳定的归属
  • La = 情感色彩变化
  • Ti = “想回家”的冲动（导音）

4.6 五声音阶：最简单的音乐语言

五声音阶（Pentatonic Scale） 是世界上使用最广泛的音阶体系。中国传统音乐、美国原住民音乐、凯尔特音乐、苏格兰音乐、非洲音乐……几乎所有古老文明都独立发现了五声音阶。

大调五声音阶：删除大调中的第4音和第7音

小调五声音阶：删除自然小调中的第2音和第6音

为什么五声音阶如此通用？

因为它天然避免了所有半音关系。在五声音阶中，任意两个音之间的最小音程是大二度（2个半音），不存在小二度、大七度等不协和的尖锐跳进。

这意味着：在五声音阶中，任意组合音符几乎都不会难听。

因此：

  • 吉他手学五声音阶是最快能上手即兴的方法
  • 很多歌曲的主旋律只用五声音阶的几个音就能概括
  • 即兴演奏遇到瓶颈时，回到五声音阶总是安全的

第五章 和弦：音符的化学反应

5.1 什么是和弦？

和弦（Chord） 是三个或更多音同时发声（或以极短间隔连续发声）形成的音组。

从”点”到”面”的质变：单个音符是一条线，和弦是一个平面。和弦赋予了音乐和声（Harmony）——不同音符同时振动时产生的物理和心理反应。

和声的基本原理是谐波共振：当两个音的频率比接近简单整数比时（如 2:1、3:2、4:3），它们听起来和谐；当频率比复杂时（如 17:11），它们听起来不协和。

5.2 三和弦：四种基本形态

三和弦（Triad） 是最小的和弦结构，由三个音构成：根音（Root）+ 三音（Third）+ 五音（Fifth）

大三和弦 vs 小三和弦的核心区别：

三度音（Third）是决定和弦大小的关键：

  • 大三度（Major Third） → 大调色彩，明亮
  • 小三度（Minor Third） → 小调色彩，柔和

五度音（Fifth）决定和弦的”紧张度”：

  • 纯五度（Perfect Fifth） → 稳定
  • 增五度（Augmented Fifth） → 不稳定，扩张
  • 减五度（Diminished Fifth） → 不稳定，收缩

5.3 七和弦：现代音乐的主角

在七和弦（Seventh Chords）中，三和弦的基础上再叠加一个七度音，形成四音和弦：

属七和弦的特别之处：

属七和弦（C7）含有三全音（Tritone）：E 和 Bb 之间的距离是6个半音（三全音），是音程协和度的分水岭。

三全音的特点是极度不稳定，它把和弦”钉”在张力状态，等待解决——这正是属七和弦制造”期待感”的核心机制。

5.4 延伸和弦：超越七度

延伸音使用原则：

  • 延伸音越多，和弦越”浓稠”——适合背景铺底，不适合主旋律
  • 旋律音优先：当前旋律正在弹奏的音应该作为和弦的一部分
  • 声部平衡：不要让低音区太拥挤，延伸音更多放在中高音区
  • less is more：在简单的三和弦上稍加延伸，比复杂和弦更有效

5.5 挂留和弦：悬而未决的张力

挂留和弦（Suspended Chord） 用二度音或四度音替代三度音，暂时”挂住”不解决：

第六章 和弦进行：流行音乐的基因密码

6.1 什么是和弦进行？

如果说音阶是音乐的”词汇表”，和弦是”词汇”，那么和弦进行（Chord Progression）就是”语法”——它决定了音乐的情感走向、乐句的结构、音乐的叙事逻辑。

不同的和弦进行像不同的”句式”：有的像陈述句一样稳定，有的像疑问句一样悬疑，有的像感叹句一样戏剧化。

6.2 功能理论：和声的化学周期表

西方和声理论把调内和弦分为三大功能（Function）家族：

为什么属和弦”想回家”？

以 G7 → C 为例：

  • G7 = G-B-D-F，含有三全音（B-F）
  • 三全音极度不稳定，两个音都”想移动”：
    • B 想下行到 C（半音）
    • F 想上行到 E（半音）
  • 结果：G7 “解决” 到 C（主和弦），三全音消失，和谐回归

经典口诀：”属和弦就像一块磁铁，永远想把主音吸过来。”

6.3 万能和弦进行：I-V-vi-IV

如果要选一个”最流行”的和弦进行，历史和现代流行音乐给出了同一个答案：I - V - vi - IV。

使用 I-V-vi-IV 的经典歌曲（据估计超过1000首）：

歌曲 艺术家 年份
Let It Be The Beatles 1970
No Woman No Cry Bob Marley 1974
With or Without You U2 1987
Zombie The Cranberries 1994
Africa Toto 1978
Sweet Child O’ Mine Guns N’ Roses 1987
Someone Like You Adele 2011
Counting Stars OneRepublic 2013

为什么它如此成功？

I → V 制造张力（属和弦的引力）
vi 提供”假出口”（意外但不唐突）
IV 柔和过渡
I 最终回归

这是一个完整的**”稳定 → 紧张 → 意外 → 回归”**的情感弧线，完美匹配人类最基本的音乐审美心理。

6.4 其他经典和弦进行

反向进行（Reversed Progression）：vi-IV-I-V 是 I-V-vi-IV 的变体，情感方向相反——从小调色彩的”内省”开始，逐步走向大调的”开放”。很多抒情ballad使用这种结构。

6.5 终止式：乐句的标点符号

终止式（Cadence） 是和弦进行的”标点符号”，决定乐句如何收尾：

假正格终止（V7 → I） 是最强烈的结束感：属七和弦的三全音引力 + 大三和弦的完全稳定 = 极致满足感。

爵士乐几乎所有”终点”都用 V7 → I（或其转位），没有它，爵士乐句就”站不住脚”。

ii-V-I 是爵士乐中最重要的和弦进行，可以称为爵士乐的”主谓宾”结构：

扩展与替代：

  • ii7 可以扩展为 ii7b9（加入b9音，更爵士）
  • V7 可以用 Tritone Substitution（隔四度替换） 变为 Db7
  • I 可以扩展为 Imaj9、Imaj7#11 等

第七章 节奏与节拍：音乐的骨架

7.1 拍子与节拍的基本概念

如果说旋律是音乐的”血肉”，和声是”皮肤”，那么节奏（Rhythm） 就是”骨架”——没有骨架，音乐就是一团松散的音符。

拍子（Beat） 是音乐的”脉搏”，规律性的强弱循环。节拍（Meter） 是拍子的组织方式。

7.2 常用节拍类型

7.3 切分节奏：打破重音的艺术

切分节奏（Syncopation） 是把重音从强拍移到弱拍，打破常规的强弱规律：

2和4拍的切分节奏是很多现代音乐风格的核心：

  • Funk：几乎所有重音都在反拍（2、4拍）
  • Disco / Dance：4/4拍下的16分音符切分
  • Reggae：1拍留空，3拍重音（反置）

7.4 复节奏与复合节拍

复节奏（Polyrhythm） 是同时使用两个或多个不同节奏型：

复节奏广泛存在于：

  • 西非和加勒比音乐（非洲根源）
  • 巴西音乐（Samba、Bossa Nova）
  • 爵士乐（特别是拉丁爵士）
  • 现代电子音乐

7.5 时值与音符长度

7.6 律动（Groove）：节奏的灵魂

律动（Groove） 是节奏在时间中的”感觉”——同样的节拍，不同的律动能带来完全不同的情绪。

影响律动的因素：

  • 音符的精确度：精确量化 vs 稍微延迟（laid back）或提前（pushed）
  • 重音的位置：自然重音 vs 切分重音
  • 音符的疏密：均匀分布 vs 密集-留白交替
  • 动态变化：每个音的强弱差异

好的律动让音乐”呼吸”，而不是机械地踩节拍器。

第八章 现代音乐的特殊语言

8.1 布鲁斯音阶：爵士与摇滚的灵魂

布鲁斯音阶（Blues Scale） 是非洲裔美国音乐的核心语言，融合了欧洲大调音阶和非洲音乐特有的”蓝调音”：

两个 蓝调音（Blue Notes）：

  • 降五度（b5）：C 和 Eb 之间的音，跨越3个半音（增二度）
  • 降七度（bb7）：G 和 A 之间的音，实际上等于 大七度的小三度版本

蓝调音在古典乐理中属于”不协和”音，但布鲁斯音乐刻意使用它们——这种以不协和创造美的思想深刻影响了爵士乐。

8.3 降二代五（Tritone Substitution）

降二代五（Tritone Substitution / Substitution Dominant） 是爵士乐中最重要的和弦替代技法：

降二代五的原理：

  • G7 的核心是三全音 B-F（不稳定）
  • Db7 的核心是三全音 Ab-Db（也是不稳定）
  • 两者都”想回家”到 C
  • 因此 Db7 可以替代 G7

经典应用：Coltrane Changes（约翰·柯特兰和弦进行）

8.5 声部进行（Voice Leading）

声部进行（Voice Leading） 是让和弦之间的每个声部尽量平滑移动的技术：

声部进行的三大原则：

  1. 共同音保持（Common Tone）：同音尽量保留
  2. 最小移动：各声部尽量半音或全音移动
  3. 反向进行：当低音上行时，其他声部尽量下行；反之亦然

第九章 经典歌曲乐理解析

9.1 The Beatles — “Let It Be”（I-V-vi-IV 的教科书）

和弦进行：C - G - Am - F (I - V - vi - IV)

乐理亮点：

  • 最经典的 I-V-vi-IV 进行
  • 全曲只用4个和弦，和弦复杂度极低
  • 但旋律极强——说明好的旋律比复杂和声更重要
  • G → Am 的连接用到了 和弦转位（G 大调的主和弦 G-B-D，以 B 为低音，即 G/B）

9.2 Adele — “Someone Like You”（降三度关系的戏剧性）

和弦进行（ verse）：D - A - Bm - F#m (I - V - vi - iii)

乐理亮点：

  • Verse 用了 降三度关系的转调（从 D 大调转到 B 大调，B 是 D 的 V 级）
  • Bm (iii) → F#m (vi) 的大跳（从第3音跳到第6音）创造”情感高峰”
  • Chorus 回到 D 大调，IV - V - I 终止感强烈

9.3 久石让 — “Summer”（调式互换与情感色彩）

和弦进行：C - G/B - Am - G - F - Em - Dm - G

乐理亮点：

  • G/B（以 B 为低音的 G 和弦）是 借用和弦
  • Em (iii) 属于 C 大调，但带有小调的柔和感
  • 变格终止（F - G - C） 用在多个乐句结尾
  • 简单的和弦 + 精美的旋律 + 独特的律动 = 永恒的作品

9.4 Radiohead — “Creep”（大三和弦的意外色彩）

和弦进行（ verse）：G - B - C - Cm

乐理亮点：

  • G → B 是 升四度跳进（极度不协和）
  • C → Cm 是 突然的色彩转换（从大调到大调的平行小调）
  • 降三度进行（C → Cm） 在流行音乐中极少见，制造强烈的”失落感”
  • 这首歌证明了：不协和不等于不好听，关键是用得恰到好处

9.5 宋冬野 — “董小姐”（五声音阶的灵魂）

和弦进行（ verse）：Am - C - F - F - G

乐理亮点：

  • 几乎只用 C 大调内的和弦，无升降号
  • 旋律基于 C 大调五声音阶（C D E G A），干净、质朴
  • Am (vi) 开场奠定了”叙述感”的基调
  • F (IV) → G (V) 的进行有轻微的”上升感”，引出副歌

10.2 创作的第一步：确定基调

开始创作前，先回答几个关键问题：

情绪方向：

  • 明亮/愉悦 → 大调
  • 忧郁/内省 → 小调
  • 神秘/超现实 → 调式互换
  • 怀旧/复古 → bVII 或 bVI 借用和弦

速度与律动：

  • 抒情 ballad（BPM 60-80）→ 和弦节奏慢，让旋律呼吸
  • 中速流行（BPM 100-120）→ 和弦节奏适中
  • 快节奏舞曲（BPM 120-140）→ 和弦节奏快，大量切分

乐器编配：

  • 钢琴/木吉他 → 开放和弦，柱式或分解
  • 电吉他 → 强力和弦（Power Chord），失真音效
  • 电子合成器 → 可尝试非常规音阶与和弦
